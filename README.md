# E-Commerce Sales & Customer Analysis

## Project Overview

This project analyzes e-commerce sales and customer behavior using Python, Pandas, SQL, and data visualization.

The objective is to identify key revenue-generating customers, products, countries, and monthly sales trends, while using SQL for business-focused analysis and aggregation.

## Dataset

The dataset used in this project is the UCI Online Retail dataset.

- **Rows after cleaning:** 392,692
- **Unique customers:** 4,338
- **Unique orders:** 18,532
- **Total revenue:** Approximately 8.89 million

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- SQLite
- Jupyter Notebook

## Analysis Performed

- Data cleaning and preprocessing
- Revenue analysis
- Customer analysis
- Product analysis
- Country-wise revenue analysis
- Monthly revenue analysis
- SQL-based business analysis
- Data visualization

## SQL Analysis

SQL was used to perform business-focused analysis including:

- Top customers by revenue
- Top countries by revenue
- Top products by revenue
- Monthly revenue trends

## Key Insights

- Total revenue was approximately **8.89 million**.
- The **United Kingdom** generated the highest revenue.
- A small group of customers contributed significantly to total revenue.
- **PAPER CRAFT, LITTLE BIRDIE** was the highest-revenue product.
- **November 2011** recorded the highest monthly revenue at approximately **1.16 million**.
- SQL aggregation helped identify high-value customers, products, countries, and revenue trends.

## Conclusion

This project analyzed e-commerce sales and customer behavior using Python, Pandas, SQL, and data visualization.

The analysis identified key revenue-generating customers, products, countries, and monthly sales trends. These insights can help businesses understand customer value, market performance, and revenue patterns.
